# AMB-1's original scenarios

These scripts were written for AMB-1's own eight pieces (a "Garden" with Pad 60 in D Dorian, "Departures" as piece 1,
and so on). In this Pocket Scion version the first four pieces are the Scion presets, so their expected values no
longer hold, and `tests/run_tests.sh` does not run them (it runs `tests/scenarios/*.amb`). They are kept as a
reference: to use one, port its piece numbers (AMB-1's pieces 1, 2, 3, 5 are now 4, 5, 6, 7; its Garden is gone)
and its Garden recipe values.
